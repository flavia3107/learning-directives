# 📌 Angular Directives Practice

This project is part of the **Angular - The Complete Guide (2025 Edition)** Udemy course.  
It focuses on practicing **Angular directives** by building a small app that **manipulates the DOM** and **enhances the UI**.

---

## ⚡ Features

- Use of **built-in Angular directives** (`*ngIf`, `*ngFor`, etc.)  
- Creation of **custom structural and attribute directives**  
- Practical examples of **dynamic DOM manipulation**  
- Demonstration of **directive reusability** and **UI enhancements**  

---

## 🛠️ Tech Stack

- **Languages**: TypeScript, HTML, CSS  
- **Framework**: Angular 16  
- **Tools**: VS Code, Git, GitHub  

---

## 🎯 Learning Objectives

✅ Master the **syntax and usage** of built-in Angular directives  
✅ Build **custom directives** for reusability  
✅ Understand how directives **control DOM elements**  
✅ Develop a **small app** showcasing these concepts
